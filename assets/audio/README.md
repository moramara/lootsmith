# LOOT SMITH - 音声アセット

## 由来とライセンス (License)

**このディレクトリのファイルはすべて [`tools/gen_audio.py`](../../tools/gen_audio.py) でゼロから合成したものです。**
(加算合成 / 減算合成を numpy + scipy で行い、BGM は ffmpeg/libvorbis で Ogg Vorbis にエンコードしています。)
録音、サンプル、サウンドフォント、ループ素材、その他の第三者の素材は一切使っていません。したがって
**帰属表示は不要で、第三者のライセンスも適用されません。** 生成スクリプトは決定的 (乱数シード固定) なので、
再実行すると同じ音が再現されます。

ファイルは、プロジェクト本体と同じ条件で LOOT SMITH 向けに提供します。他の用途で再利用する場合は
**CC0 1.0 (パブリックドメイン宣言)** として扱ってください。これが意図したライセンスです。

> 制作時には freesound / OpenGameArt などの音源サイトへインターネット経由でアクセスできず、第三者のライセンス条件を
> 確認できなかったため、意図的にオリジナルの合成を採用しました。
> **音は数値で検査してあります (レベル、クリッピング、両端、ループの継ぎ目。下記参照) が、実際に耳で聴いて確認した人はまだいません。**
> 聴いてみて、変えたい点があれば作者に伝えてください (音楽の内容はすべて `gen_audio.py` 冒頭の数個のテーブルにあります)。

再生成するには: `python3 tools/gen_audio.py` (`numpy`、`scipy`、libvorbis 付きの `ffmpeg` が必要。`--check` は測定値を表示するだけ)。

## ファイル

### BGM

| ファイル | 長さ | 形式 | 用途 |
|---|---|---|---|
| `bgm_hearth.ogg` | 80.000 秒 (3 528 000 サンプル) | Ogg Vorbis、44.1 kHz ステレオ、約 125 kbit/s | 起動時に一度だけ再生を始める、唯一のループ BGM (「Hearth and Anvil」) |

*曲調:* A マイナー / モーダルなフォーク・ファンタジー、96 BPM、4/4 拍子、32 小節 (A - A' - B - A'')。爪弾くリュートのアルペジオ、
やわらかい木製フルートの旋律、温かい弦のパッド、爪弾くベース、控えめなフレームドラム / シェイカー、そして (B パートでは)
鍛冶場へのオマージュとして、ごくかすかな金属の「チン」という音。温かく、高域が少なく、強いピークがないので、
長時間のプレイでも聴き疲れせず、効果音の入る余地も残します。

*測定値:* RMS -15.4 dBFS、ピーク -3.3 dBFS、小節ごとの RMS の変動は約 3 dB 以内 (急な音量の跳ねなし)。
エネルギーのほとんどは 80 Hz〜4 kHz にあり、25 Hz 未満にはありません。

*シームレスなループ:* 長さはちょうど整数小節で、すべての音とリバーブの残響は円環状にレンダリングしています
(最後の小節の残響が 1 小節目へ流れ込む。リバーブは円環 FFT 畳み込み)。最後の和音 (Dm) は最初の和音 (Am) に解決します。
raylib が使うのと同じデコーダ (stb_vorbis) で検証済み: デコード長はちょうど 3 528 000 フレーム、元データとサンプル単位で一致し、
先頭と末尾の 20 ms を含むどこでも SNR は約 30 dB、最後のサンプルから最初のサンプルへの段差は 0.010 です
(ファイル内で最も大きな通常の段差は 0.122)。クリックも途切れもありません。
raylib は `looping` が設定されていると、ストリームを止めずにファイルの先頭からバッファを埋め直すので、継ぎ目で音量もストリームもリセットされません。

### 効果音 (`se/`、16 ビット モノラル 44.1 kHz WAV)

ピークは、UI のチック音が控えめ (約 -12 dBFS)、通常のイベント音が -4〜-6 dBFS 前後、ファンファーレがそれよりわずかに大きい程度になるよう
選んであります。既定の音量 (BGM 35 %、SE 65 %) では、効果音は音楽から際立ちつつも、驚くほど大きくはなりません。
すべてのファイルはゼロから始まりゼロで終わり (クリックなし)、無音の尾は削ってあります。

| ファイル | 長さ | ピーク | 再生されるとき |
|---|---:|---:|---|
| `se/ui_click.wav` | 0.06 秒 | -12.5 dBFS | 通常のボタン / 決定 (木のチック音) |
| `se/ui_nav.wav` | 0.09 秒 | -13.5 dBFS | 1〜5 の画面タブ (やわらかい上昇のチック音) |
| `se/ui_back.wav` | 0.10 秒 | -13.2 dBFS | BACK ボタン、Esc での画面離脱、OPTIONS を閉じるとき (やわらかい下降のチック音) |
| `se/craft.wav` | 0.98 秒 | -1.9 dBFS | 装備のクラフト: 金床をハンマーで 2 回叩き、焼き入れのシュッという音 |
| `se/craft_rare.wav` | 1.62 秒 | -1.9 dBFS | 同上、Masterwork / Legendary 用: 上昇するきらめきが加わる |

1 回の入力で鳴る音は 1 つです。同じフレームで複数の音が候補になった場合 (例: 成功する BUY のクリック) は、
最も優先度の高いものだけが再生されます (`src/audio/sfx.c`)。`tests/test_audio.c` は、ここに挙げたすべてのファイルが存在し、
有効な 16 ビット PCM WAV であり、クリッピングせず、始まりと終わりが約 0 であること、そしてこの README がすべてのファイルに
言及していることを検査します。
